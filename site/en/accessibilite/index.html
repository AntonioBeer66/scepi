Accessibility

Status as of October 11, 2026

Accessibility: non-compliant. This statement is published before a formal RGAA audit; it does not prejudge the result of an audit.

Commitment

SCEP Invaders aims to make the site usable with a keyboard, with screen readers and on mobile. The site uses a semantic HTML structure, skip links, alternative texts and visible focus states. Some interactive features and some content still need to be checked against the RGAA.

Report a problem

If you cannot access some content, write to scep.invaders.escp@gmail.com. We will point you to an accessible alternative or send you the information in another form.

Recourse

After contacting us without a satisfactory answer, you can refer the matter to the Défenseur des droits (French Defender of Rights).

Technologies

HTML, CSS and JavaScript, with progressive compatibility depending on the browser. An RGAA audit and an action plan will be added once they have been carried out.
