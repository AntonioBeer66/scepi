## Conventions
- **Pages** : la version anglaise de `site/X/index.html` est `site/en/X/index.html` (`site/index.html` → `site/en/index.html`). Même HTML, texte traduit en anglais naturel (pas mot à mot ; garder le ton de l'original, tutoiement → "you"). Un cran de profondeur en plus : tous les chemins relatifs vers `assets/`, `manifest`, etc. gagnent un `../` (ex. `./assets/css/styles.css` → `../assets/css/styles.css`). Les liens entre pages restent dans `/en/` (relatifs entre pages anglaises). Les liens vers des pages sans version anglaise (`actus/nouveau.html`) pointent vers la version française en absolu. Les liens externes ne changent pas.
- `<html lang="en">`, `og:locale` `en_US`, `inLanguage` `en`, canonical `https://www.scepinvaders.com/en/…`, JSON-LD et meta traduits, alt/aria-label/title traduits, `skip-link` traduit.
- **Dans `<head>` de CHAQUE page (fr et en)** : `<script src="/assets/js/lang.js"></script>` (sans defer, avant les autres scripts) et deux `<link rel="alternate" hreflang="fr" href="https://www.scepinvaders.com/…">` + `hreflang="en"` + `hreflang="x-default"` (→ version française).
- **Sélecteur de langue** : dans le `<nav>` de l'en-tête de chaque page, dernier élément : sur une page française `<a class="lang-switch" data-lang="en" lang="en" hreflang="en" href="/en/…" aria-label="English version">EN</a>`, sur une page anglaise `<a class="lang-switch" data-lang="fr" lang="fr" hreflang="fr" href="/…" aria-label="Version française">FR</a>` (href racine absolu vers la page jumelle, ex. `/en/asso/` ↔ `/asso/`). Imiter l'écriture des autres liens du nav (pas d'espaces entre).
- **Code JS en modules du jeu** (`src/coinche/**`) : `import { t } from "./i18n.js"` (chemin à ajuster ; fichier `src/coinche/client/i18n.js`, déjà écrit) puis `t("texte français", "english text")` à chaque endroit où un texte est montré au joueur. Garder le français identique à l'original, caractère pour caractère, pour ne rien changer côté français. Pour les gabarits : `t(\`${n} points\`, \`${n} points\`)`. Pluriels/accords : traiter les deux langues. Les commentaires restent en français. Ne pas traduire : identifiants, clés de stockage, noms de fichiers, noms de propres (SCEP Invaders, Scepi, Coinche reste "Coinche" avec une explication si le texte le justifie, ESCP). Termes de jeu : coinche→"coinche", belote→"belote", atout→"trump", enchère→"bid", pli→"trick", dix de der→"last trick bonus (dix de der)" etc. — rester cohérent avec les règles (`REGLES_COINCHE.md`) ; les noms de couleurs : pique/cœur/carreau/trèfle → spades/hearts/diamonds/clubs.
- **Scripts classiques du site** (`site/assets/js/*.js`, hors modules) : `i18n.t("français", "english")` (objet global posé par `lang.js`).
- **Ne pas** lancer `npm run build`, `npm run deploy`, `git commit`, ni `npm test` (l'orchestrateur le fait). Autorisé : `node --check fichier.js`. Ne toucher QUE les fichiers qui te sont attribués (d'autres agents travaillent en parallèle sur les autres). Le dépôt contient des modifications non commitées de l'utilisateur dans plusieurs de ces fichiers : les conserver, n'éditer que par petits remplacements ciblés (Edit), jamais réécrire un fichier JS en entier.
